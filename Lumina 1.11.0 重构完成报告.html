本次重构内容

  1. 播放稳定性：播放新媒体时重置转码回退状态；切换媒体源从当前播放位置续播；音轨与字幕菜单展示可选轨道索引；字幕关闭状态与播放器选择保持同步；补齐 Media3 HLS/DASH 扩展依赖。
  2. 生命周期：移除播放器释放阶段不受控的 GlobalScope 上报，避免释放回调中启动脱离页面生命周期的协程；退出时通过受管理协程上报最终位置。
  3. 手机/TV：继续保留现有双端识别、TV 横屏与遥控焦点结构，手机不强制横屏；登录页、搜索及首页布局已具备窄屏适配与服务端媒体库入口。
  4. 扫码配对安全：二维码使用随机短期令牌；配置令牌一次性消费且 5 分钟过期；状态、遥控与搜索 API 要求有效配对令牌；HTTP 配置接口 POST 校验并等待电视端回调确认。
  5. Emby 通信：查询参数统一 URL 编码；服务端公共信息请求不携带账号 token；服务端错误正文对常见凭证字段做脱敏。
  6. 视觉与数据：保留现有玻璃态、页面过渡动画、服务器媒体库/题材和登录扫码界面；对首页分类入口、列表列数与手机可视区域作适配。
